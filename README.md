\# 🛒 Django E-Commerce Website



A full-featured \*\*E-Commerce web application\*\* built using \*\*Python and Django\*\*. The platform allows users to browse electronic products, manage their shopping cart, place orders, and track their order history. It also includes administrative features for managing customers, products, and orders.



\## 🚀 Features



\### 👤 User Features



\* User Registration and Login

\* Customer Dashboard

\* Browse Electronic Products

\* Product Categories

\* Product Search and Filtering

\* Add Products to Cart

\* Update Product Quantity

\* Remove Products from Cart

\* Checkout and Place Orders

\* View Order History

\* Cancel Orders

\* Return Orders

\* Update User Profile

\* Wishlist Functionality

\* Email Notifications

\* Product Images in Order Details



\### 👨‍💼 Admin Features



\* Admin Dashboard

\* View Customers

\* View Customer Orders

\* Manage Products

\* View All Orders

\* Monitor Low Stock Products

\* Sales Reports

\## ⚙️ Installation and Setup



\### 1. Clone the Repository



```bash

git clone https://github.com/SrikavyaAngam/django-ecommerce.git

```



\### 2. Navigate to the Project Folder



```bash

cd django-ecommerce

```



\### 3. Create a Virtual Environment



```bash

python -m venv myenv

```



\### 4. Activate the Virtual Environment



\#### Windows



```bash

myenv\\Scripts\\activate

```



\#### macOS/Linux



```bash

source myenv/bin/activate

```



\### 5. Install Dependencies



```bash

pip install -r requirements.txt

```



\### 6. Configure the Database



Update your database configuration in:



```text

ecommerce/settings.py

```



Then run:



```bash

python manage.py makemigrations

python manage.py migrate

```



\### 7. Run the Development Server



```bash

python manage.py runserver

```



Open your browser and visit:



```text

http://127.0.0.1:8000/

```
